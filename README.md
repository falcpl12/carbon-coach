# Carbon Coach

A free, self-contained web tool that helps small and medium businesses anywhere
lower their carbon footprint — the questions a sustainability consultant would
ask, a directional footprint, a 30/90/365-day baby-step plan, region-specific
funding help, and a peer business elsewhere that already did it.

Everything runs in the browser (no server, no API keys, no cost). Deployed as a
static site on Vercel.

## Structure

- `index.html` — the entire app (markup, styles, data, and logic in one file)
